# Heartdiseaseandwebdevlopment
# ❤️ Heart Disease Prediction using Machine Learning (Web App)

This is a final year project that uses Machine Learning and Web Development to predict the chances of heart disease based on the user’s health details. It has a clean and simple interface where the user can register, login, fill in a form, and get a prediction with health advice.

---

## 🎯 Project Overview

This project aims to help users understand their risk of heart disease using machine learning. After entering some health-related values like age, blood pressure, cholesterol, etc., the system predicts whether the person is likely to have heart disease or not.

It also stores the user’s input into an Excel file so that records can be kept for future analysis.

---

## 🧩 Key Features

- ✅ Machine Learning model trained on real heart disease data
- 🔐 User registration and login system
- 📃 Input form to collect user health data
- 📈 Prediction result shown instantly with advice
- 📝 Saves all user data (including prediction) into an Excel file
- 🏠 Homepage to explain what the app does
- 💻 Fully built using web technologies: HTML, CSS, Flask

---

## 🛠️ Technologies Used

### 👨‍⚕️ Machine Learning
- Python
- Pandas, NumPy
- Scikit-learn (Random Forest)
- Jupyter Notebook

### 🌐 Web Development
- Flask (Python-based web framework)
- HTML and CSS (Frontend UI)
- Openpyxl (For saving data in Excel)
- Bootstrap (Optional styling)
- No database used – Excel file used instead
